# [하루 요정] 프롬프트 수정 반영을 위한 개발팀 체크리스트

`AI_프롬프트_수정_스펙.md`의 프롬프트를 교체하면서 함께 확인/반영이 필요한 코드·스키마 변경사항입니다.

- [ ] **todos 스키마 변경**: 기존 `todos`가 제목 문자열(또는 title만 있는 객체) 배열이었다면, 각 항목에 `date: "YYYY-MM-DD"` 필드 추가.
- [ ] **DB 컬럼 추가**: todo 테이블/모델에 날짜 컬럼이 없다면 추가.
- [ ] **프론트엔드 그룹핑**: todos를 날짜별로 묶어서 표시하도록 렌더링 로직 수정 (현재는 날짜 구분 없이 한 리스트로 표시되는 것으로 보임).
- [ ] **중복 제거(dedup) 로직 점검**: title이 같고 date가 다른 todo/schedule을 하나로 합쳐버리는 dedup 로직이 있다면 `(title + date)` 조합 기준으로 변경. 없다면 확인만.
- [ ] **schedules 시간 저장 로직 점검**: 모델이 startTime/endTime을 반환해도 백엔드에서 isAllDay를 강제로 true 처리하거나 시간 값을 누락시키는 부분이 없는지 확인.
- [ ] **memo.title 고정값 영향 확인**: 목록 화면에서 memo.title을 식별자/미리보기로 쓰고 있다면 모든 메모 제목이 "메모에 등록할게요."로 동일해짐 → 필요 시 body 앞부분을 잘라 미리보기로 대체 검토.
- [ ] **memo.body 길이 대응**: 여러 사건을 종합하면서 body가 길어질 수 있음 → UI 표시 영역 길이 제한/줄바꿈 확인.
- [ ] **대화 모드 / 정리 모드 프롬프트 분리 확인**: 현재 코드가 두 모드 프롬프트를 하나로 합쳐서 매번 통째로 모델에 전달하고 있다면, mode 값에 따라 필요한 프롬프트만 전달하도록 분리 (불필요한 지침 혼입으로 인한 출력 오염 및 토큰 낭비 방지).
